PRIVATER RAUM

Ohne Tyjora-Konto: Wer denselben Code eingibt, spielt zusammen.

🍀

SO GEHT'S

  • Ziel: Sammle als Erste:r die eingestellte Zahl an Reisepass-Stempeln. Einen Stempel gibt es, wenn du den Koffer 🧳 erreichst und für 50 T-Coins öffnest. Danach taucht der Koffer auf einem anderen Kontinent auf – jeder Kontinent kommt nur einmal dran.
  • Zug: Erst (wenn du willst) ein Item benutzen, dann würfeln. An Abzweigungen wählst du den Weg. Über die Ozeane geht es gratis per Boot ⛵ (hellblaue Felder) oder schnell per Flugzeug ✈ von Flughafen zu Flughafen (8 T-Coins).
  • Minispiel: Wenn alle gewürfelt haben, startet ein Minispiel. Es gibt T-Coins für alle und Items für die ersten drei.
  • Leben ❤: Bei 0 Leben bist du K.O.: Du verlierst die Hälfte deiner T-Coins, landest am Flughafen und setzt einmal aus.
